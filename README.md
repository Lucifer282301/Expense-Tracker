# Expense-Tracker
This expense tracker lets users manage income and expenses with secure login, a clear dashboard, category tracking, interactive charts, recent transactions, and Excel report downloads. It works smoothly on all devices and offers simple navigation with quick delete actions for easy record management.

Features : 

**1. User Authentication**

Secure login and sign-up with JWT based authentication.

**2. Dashboard Overview**

Shows total balance, income, and expenses in clear summary cards.

**3. Income Management**

Add, view, delete, and export income entries.

**4. Expense Management**

Add, view, delete, and export expenses with category tracking.

**5. Interactive Charts**

Visual breakdown of income and expenses with bar, pie, and line charts.

**6. Recent Transactions**

Quick view of the latest income and expense records.

**7. Reports**

Download income and expense data in Excel format.

**8. Responsive UI**

Works smoothly on desktop, tablet, and mobile.

**9. Simple Navigation**

Sidebar with quick access to Dashboard, Income, Expenses, and Logout.

**10. Quick Delete**

Hover on income or expense cards to reveal a delete option for faster actions.
